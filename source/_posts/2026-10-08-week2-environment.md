## 虚拟机

装了个 Ubuntu 虚拟机，在 VMware 里。

**但装完之后里面基本是空的。** 本来想的是"Linux 就放虚拟机里"，结果发现平时用 Windows 顺手，截图、查资料、开浏览器都在 Windows，来回切太麻烦，最后东西全装在 Windows 上了。

虚拟机现在就当个摆设，偶尔开起来敲两个命令熟悉一下。

## Windows 上装的几样

**VS Code**：写代码用。加了个中文语言包，又装了 Python 的扩展。之前一直用记事本，换了之后至少括号能自动配对。

**Git**：上周就装过，这周把它和 GitHub 连上了。配名字、配邮箱，然后试 `clone`、`add`、`commit`、`push`。第一次把自己的改动推上去、刷新网页看到内容真变了，还挺有成就感。

现在只会在 main 上直接改，分支那套还没看。

**Python3**：装完在终端敲 `python --version` 能出版本号就算成。还没写什么正经东西，就是照着教程跑了几行。

## Burp Suite

这周花时间最多的一个。

装的是 Pro 的汉化版，菜单是中文的，对着教程找功能方便点。

**抓包我用的是 Burp 自带的那个浏览器。** 一开始还打算去配 Chrome 的代理，后来发现 Burp 里直接有个内置浏览器，点开就是配好的，省了一堆事。

在里面随便点一个网站，Burp 就能看到请求了。原来登录就是把账号密码放在一个 POST 请求里发出去，长的像 `username=admin&password=123456`。以前完全不知道点一下"登录"背后发生了什么，现在至少能看见那一行字。

爆破用 Intruder。思路是把要猜的位置选中、标成 `§这样§`，再挂一个字典让它一个个试，模式选 Sniper 就够。跑起来就是看着它一列一列试，试到不一样的那个大概就是答案。

我现在的水平也就是会用，原理还说不太清楚。为什么有的网站试几次就被拦了，我也不明白。

## CTF 新手赛

十月初，几个学校一起办了个 CTF 新手赛，我也报了。结果差得太远 —— 题面基本看不懂，看着最简单的也卡在那儿。

最后挑了三道去问 Codex，让它一步一步讲给我听。下面这些是我听完之后大概记住的，离自己做出来还差得远。

### 签到（Crypto）

附件是一串只有 `A` 和 `B` 的密文，一共 120 个字符，提示是"超过 4 层栅栏能吃到 24 块培根"。

看到"栅栏"我就往上下折返的那种栅栏密码上想了，怎么排都不对。后来才知道这里的 4 层不是折返，是**把密文横着切成 4 行，再竖着一列一列读下来**，读完顺序才对得上。

"培根"是培根密码，5 个 `A/B` 当一个字母，`A` 算 0、`B` 算 1，而且用的是 24 个字母的那张表，比常见的那张少两个字母。

两步我都没往那想，尤其第一步，"栅栏"跟我以为的完全不是一回事。

### Web

是一个做短链接的站。首页自己就写着：短码 4 位，用 `0-9` 和大小写字母，一共一千四百多万种。

我沿着"先看看有没有别的入口"这个方向，扫了一小段纯数字的短码，看它们都跳到哪去。扫了几百个之后碰上一个，跳过去是管理员重置密码的页面。

密码重置掉，用新密码登进去，后台页面上直接就是 flag。

回头想想，这题其实不难，难的是我一开始不知道该往哪看。我还绕去猜短码是怎么生成的、去试能不能伪造登录状态 —— 全是白费功夫。

### pwn：第一次开 Ghidra

这道题只给了一个 Linux 的可执行文件，没有源码，要把它拆开看里面藏了什么。

会去装 Ghidra 就是因为这题。装之前得先有 JDK，我机器上是 JDK 8，它起不来，报的是找不到 JDK 21 以上；换了才打开。还有项目路径不能带特殊符号，我一开始那个目录名里有个弯引号，直接不让建。

装好之后把文件拖进去，它自己分析一阵，出来好几块窗口：中间是反汇编，左边一列函数，右边是反编译出来的 C 代码。右边那个 C 看着还挺像回事，比直接啃汇编舒服多了。不过里面全是 `undefined8`、`DAT_xxx`、`local_xx` 这类名字，我一开始以为是自己哪儿弄坏了，后来才知道没有源码就是这样。

按 Codex 讲的，这题是两处没做检查凑在一起：一处是往数组里写的时候下标没拦负数，能写到数组前面的变量上去；另一处是拿数组里存的下标去调函数，下标超了也不管。两个接起来，就能拐到那个会打印 flag 的函数上。

思路我听得懂，但要我自己从那堆反编译代码里把这两处找出来，肯定找不到。而且到现在也没真跑起来验证过 —— Windows 上跑不了 Linux 的可执行文件，还得再折腾个环境。

这题能看懂的部分，估计不到一成。

跟 Burp 那边完全是两个路子：Burp 看的是程序发出去的请求，Ghidra 看的是编译好的程序本身。两个都算刚摸到门，离会用还远。

## 中转站

模型没用官方 API，走的是中转站，比官方便宜不少。Codex 和 Claude 都是。中间用一个小工具叫 cc switch 切配置。

这块纯配置，照抄就行，没什么好说的。

## 这周学的零碎东西

**命令行和权限**：从终端怎么用开始看的，`ls`、`cd`、`mkdir` 这些先过了一遍，后面讲到文件和权限。`ls -l` 出来那一串 `rwx` 字母，看了才知道是给不同人分的权限。`chmod` 能改，但具体什么时候该用哪个数字，我还得翻着表来。

**CS50x 第一周**：讲 C。上周跟着鹏哥的视频过了一遍语法，再看 CS50 感觉它铺得比较开，一节课里掺的东西挺多。

## 顺手知道的几个词

- **Markdown**：写笔记用。`#` 是标题，三个反引号是代码块，比 Word 好使。
- **HTTP**：知道一个请求大概长什么样了 —— 开头一行说明要干什么，然后一堆头，然后才是内容。以前对我来说就是个黑盒。
- **HTML / CSS / JS**：知道网页是这三样拼起来的。HTML 是结构，CSS 是长相，JS 管点了之后干什么。也就是知道，自己写还写不出来。

国庆七天，我玩了四天。说实话基本没学啥。

**左四右二（求生之路 2）**：这游戏我玩得挺久了，但一直只会下现成的 mod。这回终于搞懂了怎么用 l4n 给武器装音频库 —— 以前听别人视频里枪声跟我的不一样，还以为得自己会做 mod 才行，其实有个现成的工具，跟着教程走一遍就明白了。装完自己听着是舒服。

**地平线五**：开车的。这个解压，跑完步回来开两把挺合适。假期基本就是这两个游戏来回切。

## 想起小学那会儿

闲着的时候突然想起来，小学我也这么折腾过电脑。

那时候家里那台机器上装着 xash（跑 CS1.6 用的引擎），我整天搞 CS1.6 的模型：换皮肤、换枪模、改贴图，一弄就是一下午。作业基本没好好写，成绩也就那样。到高中才真的后悔，觉得那几年全白玩了。

结果现在考上了哈理工，回头再看，突然觉得好像也没什么 —— 学还是照上，专业还是计算机。

甚至有点觉得，现在对计算机这点感觉，就是从那时候搞模型攒下来的。改贴图、改模型文件、看别人怎么做 mod，说白了就是在跟文件格式、路径、一堆工具打交道，只不过当时不知道这些词。可能真是命中注定让我学这个的吧。

话说回来，现在连 CTF 最简单的题都看不懂，这话还是说早了。
